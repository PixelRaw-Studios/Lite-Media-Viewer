# Code of Conduct

We are committed to making participation in Lite Media Viewer welcoming and respectful for everyone.

Be considerate, communicate constructively, respect differing viewpoints, and focus criticism on ideas and work rather than people. Harassment, discriminatory language, threats, and personal attacks are not acceptable.

Project maintainers may remove content or restrict participation when necessary to address behavior that violates these expectations. Report concerns privately to a project maintainer through their GitHub profile.
