# Security Policy

## Supported versions

Security fixes are intended for the latest published version. Older versions may not receive updates.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** feature. Otherwise, contact a maintainer privately through the contact information on their GitHub profile.

Include the affected version, steps to reproduce, and potential impact. Please allow maintainers reasonable time to investigate before publicly disclosing a report.
