# Contributing

Thanks for your interest in improving Lite Media Viewer.

## Before making a change

- Open an issue to discuss substantial changes before starting work.
- Keep pull requests focused and explain the user-visible effect.
- Do not include generated executables, private activation data, or third-party binaries.

## Build and check

Build on Windows by running `build.bat` from the project directory. There is currently no automated test suite. For changes to the app, manually check the affected behavior and avoid overwriting the original media file during editing tests.

For pull requests, include a concise description, the checks you ran, and any relevant screenshots for UI changes.
